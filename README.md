# Student Performance Prediction System

## 📌 Project Overview

This project uses Machine Learning to predict a student's final score based on:

* Study Hours
* Attendance
* Previous Marks
* Assignment Score

A Linear Regression model is used to make the prediction.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Streamlit

## ⚙️ How It Works

1. Student details are entered through the web interface.
2. The data is given to the trained Machine Learning model.
3. The model predicts the student's final score.
4. The predicted score is displayed on the webpage.

## 📊 Machine Learning Model

The project uses **Linear Regression**.

The model is trained using a small educational demonstration dataset.

## ▶️ How to Run

Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn streamlit
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Project Goal

The goal of this project is to understand the basic workflow of a Machine Learning project, from collecting data and training a model to making predictions through a simple web application.
